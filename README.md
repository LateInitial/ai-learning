# ai-learning

A public working log of a six-month push into applied AI — the study, the
notes, and the things I build along the way.

## Why this exists

Most learning happens invisibly and then gets summarised after the fact, at
which point it's unverifiable. This repo is the opposite: a timestamped,
append-only record kept as it happens. If a claim about what I know shows up
somewhere else, the working is here.

The focus is deliberately narrow. There is no shortage of people learning AI
in general. There are far fewer working at the intersection of AI and
Indonesian capital markets, commodities, and financial regulation — so that
intersection is where the builds point.

## Structure

| Path | Contents |
|---|---|
| `learning-log.md` | Daily entries: what I studied, built, and got wrong |
| `notes/` | Per-course and per-topic notes, one file each |
| `builds/` | Working tools, each in its own subfolder with its own README |

## Roadmap

Five stages over roughly 26 weeks:

1. **AI literacy** — vocabulary, capabilities, limits
2. **Technical foundations** — Python for data, ML fundamentals
3. **GenAI and agents** — LLMs, RAG, agent architectures, evaluation
4. **Strategy and governance** — adoption, ROI, NIST AI RMF, EU AI Act,
   Indonesia's Stranas KA and PDP Law
5. **Portfolio** — assessments, case studies, and public write-ups
